# to_be_reviewed

Put the product here: its Quarto source (`.qmd`), its rendered PDF, or both. With more
than one of a kind, name the files in `cfg` in `review.qmd`.

The demo, from the kit's root folder:

```bash
cp demo/sse/DEMO-TKA_SSE.qmd demo/sse/DEMO-TKA_SSE.pdf tools/2-api/to_be_reviewed/
```

Nothing in this folder is committed but this file. Put only documents here that your
data rules allow you to send to the provider; never patient-level data.
